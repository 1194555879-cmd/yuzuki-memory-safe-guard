# 柚月记忆安全护栏 v0.2.0

## 这版解决什么

### 1. 存档级硬锁
不再只拦截柚月公开的 FloorHider 函数。

- 为普通 user / assistant 消息安装 `is_system` 属性护栏。
- 柚月或其他路径试图把普通对话写成 `is_system=true` 时，立即拒绝。
- 在 `saveChat` / `saveChatConditional` 执行前再次清洗聊天。
- 如果消息对象被替换，会通过内容与时间指纹恢复已知的正常对话。
- 柚月生成的总结、表格、向量和记忆数据不受影响。

### 2. 总结 / 追溯保险锁
发现以下明显信号时，会阻止柚月开始总结或追溯：

- 页面仍有 `Show more messages / 加载更多消息`。
- TauriTavern 元数据声明的消息总数大于当前插件读到的数量。

保险锁只拦截能够可靠识别的情况。手机端完整历史桥仍需后续单独开发，因此目前完整总结仍优先在电脑 SillyTavern 执行。

### 3. 低耗电
- 不再每秒扫描。
- 主要依赖消息事件、保存前检查、回到前台检查。
- 每分钟只做一次兜底健康检查。

## 首次测试

1. 原始正式档保持备份。
2. 在测试副本中同时开启柚月和护栏。
3. 运行一次 5～10 层的小总结。
4. 立刻导出 JSONL 检查。
5. 未验收前不要用唯一主档测试。
