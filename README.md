# 柚月记忆安全护栏 v0.6.0

## 新增：后台自动化保护

柚月当前会在 `GENERATION_ENDED` / `CHARACTER_MESSAGE_RENDERED` 后延迟调度自动小总结、自动大总结和自动批量填表。v0.6.0 会在角色回复落地后自动读取完整历史，并保留五分钟安全窗口，让后台任务取得真实总楼层，而不是 TT 当前窗口里的约 50 层。

若完整历史读取失败：

- 自动取消柚月当前待执行任务；
- 不允许它按残缺的 50 层上下文继续总结或追溯；
- 显示错误提示，下一轮再重试。

用户发送下一条消息时，旧的完整历史快照会立即释放；角色新回复落地后重新读取，避免使用过期内容。

## 保留功能

- 悬浮球常驻显示真实总楼层。
- 打开柚月面板自动加载完整历史。
- 手动总结、追溯、重试和批次按钮先桥接完整历史再执行。
- `Cursor signature mismatch` 自动从头重试，最多三次。
- 阻止柚月把原聊天楼层标成 `is_system` 后保存。
- 关闭面板后释放面板专用历史副本。

## 自动化测试顺序

1. 先导出当前聊天 JSONL 留底。
2. 只开启一个低门槛自动任务，例如“自动小总结”，间隔临时设为 2～4 层。
3. 发送一条消息并等待角色回复。
4. 不打开柚月面板，等待自动任务完成。
5. 再打开面板检查：
   - 总楼层仍是真实数量；
   - 自动总结范围包含最新楼层；
   - 没有 `Cursor signature mismatch`；
   - 没有凭空出现物品；
   - 聊天没有退回或保存成 50 层。
6. 通过后再恢复平时的自动化间隔，并逐项开启其他自动任务。

首次测试不要同时开启自动小总结、自动大总结和自动批量填表。
