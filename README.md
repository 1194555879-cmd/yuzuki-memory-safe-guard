# 柚月记忆安全护栏 v0.5.0

## 新增：按需全量历史桥
- 正常聊天时不保存完整历史副本。
- 点总结、追溯、重试本批等按钮时才临时读取完整历史。
- 任务完成、超时或切换聊天后自动释放。
- 最后一楼的沙盒边界修复仍然保留。

## 新增：手机性能守护
它会观察帧率、主线程延迟、长任务、DOM 节点和 iframe 数量。

状态提示：
- 轻微卡顿：提示“当前有点卡，正在观察”。
- 严重卡顿：自动进入可逆轻量模式。
- 恢复流畅：提示“页面已恢复，可以继续操作”。

轻量模式只临时关闭动画、过渡、模糊背景和高开销阴影；不会删除消息，也不会修改聊天、角色卡、世界书、正则或柚月记忆。

## 更新方法
覆盖 GitHub 仓库中的 manifest.json、index.js、style.css、README.md，然后在 TauriTavern 更新扩展并彻底重启。

## 第一次测试
1. 先用测试档。
2. 打开聊天停留 20～30 秒，平时不应看到“柚月全量”悬浮按钮。
3. 手动点一次总结或追溯，应先显示“正在准备完整历史”，随后自动继续。
4. 任务结束后完整历史副本会自动释放。
5. 快速切换几个大面板，观察卡顿与恢复提示。

## 注意
柚月后台自动化仍建议暂时关闭。v0.5 可靠拦截的是手动点击触发的总结、追溯和批次按钮。性能阈值是第一版保守参数，后续可按你的 iPhone 实际表现微调。
