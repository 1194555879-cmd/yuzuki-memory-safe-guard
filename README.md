# 柚月记忆安全护栏 v0.3.0

## 新增：TauriTavern 全量历史桥

TauriTavern 官方说明，窗口模式下 `getContext().chat` 只包含最近一段消息；完整历史应通过：

- `window.__TAURITAVERN__.api.chat.current.windowInfo()`
- `handle.history.tail()`
- `handle.history.before()`

读取。

v0.3 使用这套官方 API 在 Rust 后端分页读取完整聊天，**不会把全部楼层渲染到手机页面**。

## 新增：隔离沙盒

启用全量桥后：

- 柚月读取的是完整历史的独立副本。
- 柚月即使尝试写 `is_system=true`，也只会改副本，不会改原聊天。
- 柚月保存总结时，仍保存到真实聊天的 metadata；原始消息数组不被替换。

## 使用方法

1. 打开要处理的聊天。
2. 点击左下角 `🧠 柚月全量 50/75`。
3. 等提示“全量历史桥已启用”。
4. 关闭并重新打开柚月面板。
5. 确认柚月显示完整总楼层，例如 `共 75 层，末楼层 74`。
6. 再执行总结或追溯，建议每批 10 层。
7. 完成后重启 TauriTavern，自动恢复普通窗口模式。

## 注意

- 这是首次真实环境测试版，先使用测试副本。
- 全量桥默认 30 分钟后自动关闭。
- 桌面 SillyTavern 也可点击该按钮启用隔离沙盒，但完整历史本来已在内存中。
