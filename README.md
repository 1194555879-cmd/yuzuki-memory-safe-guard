# 柚月记忆安全护栏 v0.4.0

## 新增功能

### 自动全量历史桥
- 打开聊天后自动读取完整历史。
- 收到新消息、编辑、删除、切换聊天后自动刷新。
- 手动点总结/追溯时，如果桥尚未就绪，会先自动加载；失败则取消任务。
- 不再要求每次手动点“柚月全量”。

### 最后一楼边界修复
柚月的总结区间采用左闭右开，但界面又不允许结束值超过末楼层，导致最后一楼永远选不到。

v0.4 会在**沙盒副本**末尾添加 1 条内部边界占位：

- 真实聊天 75 条：`#0～#74`
- 柚月沙盒看到 76 条：`#0～#75`
- 选择 `74 → 75` 时只处理真实 `#74`
- `#75` 为空白系统占位，不属于真实聊天，也不会写回存档

因此柚月面板会暂时显示“共 76 层，末楼层 75”，这是正常的边界修复，不是多出了一条真实聊天。

### 悬浮按钮自动隐藏
- 自动桥成功后按钮透明隐藏，不再占屏幕。
- 只有加载中、失败或尚未启用时才显示。
- 失败时可以点按钮手动重试。

## 首次测试

1. 使用测试副本。
2. 更新后彻底重启 TauriTavern。
3. 打开聊天并等待几秒。
4. 打开柚月：真实 75 条时，应显示共 76 层、末楼层 75。
5. 用 `74 → 75` 测试最后一楼总结。
6. 导出 JSONL 检查：真实消息仍应只有 75 条，且没有 `is_system=true` 的普通对话。

## 自动化说明
v0.4 会在打开聊天和消息变化后自动维持全量桥，已经具备自动任务运行所需的前置条件。但首次版本仍建议先完成手动总结、追溯验收，再逐项开启柚月自动化。
