# 柚月记忆安全护栏 v0.7.0-beta.2

## 修复：自动小总结开启后一直不触发

Beta.1 的完整历史快照末尾带有一个仅供手动追溯使用的 system 边界占位符。
柚月自动调度器会检查当前聊天的最后一条是否为角色回复；看到这个 system
占位符后，它会直接判定“最后一条不是 assistant”，因此自动任务永远不会启动。

Beta.2 已修复：

- 自动任务取得完整历史后，移除末尾边界占位符；
- 柚月能正确识别最新一条角色回复；
- 从 `MESSAGE_RECEIVED` 开始提前准备历史，不必等到生成结束后才读取；
- 合并 `MESSAGE_RECEIVED`、`GENERATION_ENDED`、`CHARACTER_MESSAGE_RENDERED`
  三个连续事件，不再反复重置自动任务窗口；
- 保留普通回复隔离、Claude 80 万上下文锁、真实楼层和手动批次保护。

## 你的当前档会怎么补

当前最新小总结停在 120–129，设置为每 10 层、延迟 2 层。
当前总楼层已经超过 142，因此更新后再完成一轮角色回复时，柚月应自动补：

- 130–139

后续仍有满足条件的积压时，柚月会按自己的回填节奏继续处理。

## 首次验收

1. 保持自动小总结开启。
2. 自动大总结和自动填表继续关闭。
3. 更新护栏并彻底退出 TauriTavern 后重开。
4. 正常聊一轮，不打开柚月面板，也不点悬浮球。
5. 角色回复结束后等待约 5–20 秒。
6. 打开记忆总结，确认新增 130–139。
7. 若没有新增，先不要继续多聊，截图日志查看器和当前总结指针。

## 回退

出现卡顿、白屏、百万 token 或错楼时，立即关闭自动化并回退 v0.6.3。
