# 柚月记忆安全护栏 v0.6.3

## 修复：批量总结隔一批失败

已定位到的表现：

- 第 1 批正常；
- 第 2 批提示“范围内无有效聊天内容”；
- 点击“继续后续批次”后第 3 批正常；
- 第 4 批再次提示相同错误；
- 第 5 批又能完成。

原因是柚月批量任务在两个批次之间会短暂退出“执行中”状态。旧护栏误以为任务已经结束，释放了完整历史桥；下一批只看到 TauriTavern 当前约 50 条窗口，因此按绝对楼层取数时得到空范围。

v0.6.3 会在检测到以下界面时持续保持完整历史：

- “当前批次 X/Y”
- “第 X 批执行失败”
- “继续后续批次”
- “重试本批”
- “停止任务”

直到整个批量窗口结束，才允许释放完整历史。

## 保留功能

- 悬浮球显示真实楼层；
- 打开柚月面板自动同步；
- 手动总结和追溯前自动加载完整历史；
- 普通生成前释放全量桥；
- Claude 上下文发送前锁定为 800000；
- Cursor signature mismatch 自动重试；
- 防止真实聊天被错误标记成系统消息并保存。
