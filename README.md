# 柚月记忆安全护栏 v0.7.0-beta.1

## 终于接上后台自动化了

柚月 0.4.9 的自动任务会在角色回复生成结束后启动调度，并直接从
`SillyTavern.getContext().chat` 读取总楼层与指定范围。TauriTavern 长档平时只暴露约
50 条窗口，因此自动任务需要在真正取数时看见完整历史。

这版采用“一次性自动任务窗口”，不再像旧实验版那样把完整历史常驻五分钟：

1. 只有你在柚月设置里**明确开启**自动小总结、自动大总结或自动批量填表时才工作。
2. 角色回复结束后，护栏立刻开始读取完整历史。
3. 读取期间临时把柚月标记为“插件忙碌”，让它自己的调度器延期 2 秒重试，避免抢先按 50 层计算。
4. 完整历史准备好后，仅保留给柚月自动任务使用。
5. 检测到 `window.isSummarizing` 后确认任务真正开始。
6. 任务结束并经过自动回填宽限期后立即释放。
7. 你发送下一条、继续、重生成或 Swipe 时，自动窗口会先被取消并释放，普通 Claude 回复不会吃到完整聊天。
8. 完整历史读取失败时，调用柚月自己的 `cancelPendingAutoTask()`，本轮不执行残缺任务。

## Beta 首测只开一个功能

请先导出测试聊天 JSONL，然后：

1. 在柚月里只开启“自动小总结”。
2. 关闭自动大总结、自动批量填表。
3. 把小总结间隔临时设为 2～4 层，延迟设为 0～1 层。
4. 选择直接触发/自动保存，第一次不要使用弹窗确认。
5. 正常聊一轮，等待自动小总结自行完成。
6. 打开柚月面板检查：
   - 总楼层仍是真实数字；
   - 总结范围包含最新楼层；
   - 没有“范围内无有效聊天内容”；
   - 没有 Cursor signature mismatch；
   - 普通角色回复没有百万 token；
   - 聊天 JSONL 没有退成 50 层。

通过后，把间隔恢复到日常值，再单独测试自动大总结；自动批量填表最后测试。
