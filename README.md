# 柚月记忆安全护栏 v0.5.2

## 这一版解决什么

- 不再要求每聊一轮就手动点悬浮球。
- 护栏每 5 秒从 TauriTavern 的 `windowInfo.totalCount` 刷新真实楼层数。
- 打开柚月记忆面板后，会自动加载完整聊天历史，并把面板中的“当前末楼层 / 共 N 层”修正为真实数量。
- 点击总结、追溯、批次执行等按钮时，如果完整历史尚未准备好，会先拦截操作，读取完整历史后再自动继续。
- 关闭柚月面板后，完整历史副本会自动释放，避免一直占用手机内存。
- `Cursor signature mismatch` 会从头重新读取，最多重试 3 次；仍失败则取消本轮任务，不会带着 50 层残缺视图继续执行。
- 继续阻止柚月把真实聊天楼层标成 `is_system` 并保存。

## 更新方法

将以下 4 个文件覆盖到 GitHub 仓库根目录：

- `manifest.json`
- `index.js`
- `style.css`
- `README.md`

提交后，在 TauriTavern 的扩展管理中更新扩展，并彻底退出 App 后重新打开。

## 第一次测试

1. 自动化先保持关闭。
2. 打开一张超过 50 层的测试聊天。
3. 不点悬浮球，直接打开柚月面板。
4. 顶部应短暂显示“正在同步真实楼层”，随后面板显示真实总楼层。
5. 发一轮消息，再次打开面板；总楼层应自动增加，不应固定在 50。
6. 手动执行一次 2～3 层的追溯，确认没有 `Cursor signature mismatch`。
7. 测试稳定后再讨论后台自动化保护；v0.5.2 仍以手动任务和面板自动桥接为主。

## 回退
