# 柚月记忆安全护栏 v0.6.2

## 新增：Claude 80 万上下文安全锁

TauriTavern 2.1.1 / SillyTavern 前端可能出现以下现象：

- 关闭“解锁上下文长度”并保存；
- 把上下文改成 800000；
- 重新打开后又显示 2000000；
- 长档最终撞到中转的 100 万 token 上限。

v0.6.2 不再依赖这个界面是否保存成功。只要当前路由或模型名称能识别为 Claude / Anthropic / Opus / Sonnet / Haiku：

- 发送、继续、重新生成、Swipe 前检查上下文；
- 若“解锁”被打开，自动关闭；
- 若上下文高于 800000，自动压回 800000；
- 先修正内部 `oai_settings`，再继续原本的生成操作；
- Gemini、GPT、DeepSeek 等非 Claude 模型不受影响。

这是“运行时安全锁”，不保证 TT 的设置界面永远不再显示 2000000；即使界面又跳回去，实际发送前仍会被护栏拦下并改回 800000。

## 仍然保留

- 悬浮球显示真实总楼层；
- 打开柚月面板自动同步完整历史；
- 手动总结、追溯前自动准备完整历史；
- 普通角色回复生成前释放全量历史桥；
- `Cursor signature mismatch` 重试；
- 防止原聊天被错误标成系统消息后保存。

## 使用

覆盖 GitHub 仓库根目录的：

- `index.js`
- `style.css`
- `manifest.json`
- `README.md`

更新扩展后彻底退出 TauriTavern，再重新打开。

后台自动总结和自动填表仍先保持关闭。
