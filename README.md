# 柚月记忆安全护栏 v0.6.1

## 紧急修复

v0.6.0 为后台自动化保留了较长时间的完整历史桥，可能让下一次正常角色回复也读取整份聊天。长档会因此出现：

- `prompt is too long`
- 百万 token 请求
- 发送或编辑时卡顿
- 页面切换后白屏

v0.6.1 已移除这套后台常驻保护，恢复为稳定的按需模式，并新增一道保险：

- 点击发送、继续、重新生成、Swipe 等普通生成控件前，立即释放完整历史桥；
- 在输入框按 Enter 发送前，也会立即释放；
- 柚月自己的总结、追溯按钮不受影响，仍会先读取完整历史再执行；
- 打开柚月面板时仍会自动同步真实楼层；
- 悬浮球仍显示真实总楼层。

## 当前使用规则

- 普通聊天：无需点击悬浮球。
- 查看柚月面板：自动同步。
- 手动总结/追溯：护栏自动准备完整历史。
- 后台自动总结/自动填表：暂时保持关闭，等待专门钩住柚月任务入口的后续版本。

## 更新方法

覆盖 GitHub 仓库根目录中的：

- `index.js`
- `style.css`
- `manifest.json`
- `README.md`

提交后，在 TauriTavern 更新扩展并彻底退出 App 后重开。
